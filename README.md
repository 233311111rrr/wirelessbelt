# Wireless Belt (Mindustry v8 / 160.x Java mod)

- Wireless Belt: sender / receiver, many-to-many links, direct links to turrets and other buildings, item filter
- Batteries x5 / x10 / x20 / x30 (heat + coolant for x10 and up)
- Ultra Drill

Every push builds the Android jar and publishes it as a GitHub Release.
